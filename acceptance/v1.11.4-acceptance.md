# v1.11.4 验收记录（publication-state reconciliation）

- 版本：`1.11.4`
- 发布轨：`latest`
- 范围：对账 `v1.11.3` 的发布状态，更新版本与长期发布文件，不扩大 `verified` 或 public API

## 结论

`v1.11.4` 是 publication-state reconciliation patch：它把 package、toolkit 常数、双语 README、roadmap、support matrix、CLI 构建说明与 npm 发布说明对齐到同一版本口径，同时把易腐化的精确远端状态移入版本 acceptance。

- 不新增 CLI 命令
- 不修改 `DoctorReport`、`CapabilityDefinition` 或 `nextActions[]` wire shape
- 不把 preview / experimental capability 提升到 `verified`
- 不把 debug/release HAP build pass、simulator install/start 或 app-shell smoke 表述成真机 device pass 或 per-capability runtime pass

## 发布状态对账

| Surface | `v1.11.3` 对账结果 | `v1.11.4` 记录 |
| --- | --- | --- |
| 初始 readiness | 未创建 tag、发布 npm 或创建 GitHub Release | 历史状态保留在 `v1.11.3-acceptance.md` |

| 长期发布文件 | 不保留会腐化的 npm dist-tag 或“尚未发布”现况句 | 精确远端状态只留在 acceptance |
